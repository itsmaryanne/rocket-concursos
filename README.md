# Rocket Concursos 🚀

Plataforma gratuita de acompanhamento de estudos para concursos públicos, desenvolvida para ajudar estudantes a organizar sua preparação, monitorar seu desempenho e acompanhar sua evolução até a aprovação.

## Sobre o projeto

O Rocket Concursos é uma plataforma criada para facilitar o planejamento e o acompanhamento dos estudos para concursos públicos.

A proposta é oferecer ferramentas que permitam visualizar o progresso individual, identificar dificuldades e manter uma rotina de estudos organizada.

## Funcionalidades

- [X] Organização de matérias e conteúdos
- [X] Registro de sessões de estudo
- [X] Acompanhamento de desempenho
- [X] Controle de revisões
- [X] Identificação de dificuldades
- [X] Registro de simulados
- [X] Definição e acompanhamento de metas
- [ ] Gráficos de evolução

## Tecnologias utilizadas

- Front-end: HTML, CSS e JavaScript.
- Armazenamento: localStorage.
- Exportação e importação: JSON.

## Armazenamento de dados

Atualmente, os dados são armazenados localmente no navegador por meio do localStorage.

> **Atenção:** os registros ficam vinculados ao navegador e dispositivo utilizados. Limpar os dados de navegação ou o armazenamento do site pode apagar suas informações.

Para evitar a perda de dados, a plataforma disponibiliza recursos de exportação e importação em JSON, permitindo criar cópias de segurança e recuperar seus registros posteriormente.
