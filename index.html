Suporte

Dúvidas frequentes sobre o funcionamento do site.

Onde ficam salvos os meus dados?

Somente neste navegador e neste dispositivo. Acessar por outro aparelho não mostra seus registros.

Como faço para não perder meus dados?

Use “Exportar backup” (no rodapé) com frequência. Para levar os dados a outro aparelho, exporte lá e use “Importar backup” aqui.

Limpei o navegador e perdi tudo. Dá para recuperar?

Só com um backup exportado antes. Sem backup, não há como recuperar os dados.

Como funciona o ID do perfil?

É um número de 5 dígitos gerado ao criar o perfil. Você usa o ID e a senha para entrar, e compartilha o ID para receber pedidos de amizade.

Seus dados ficam só neste navegador

Os dados são guardados localmente neste navegador e neste dispositivo, isto é: acessar o site por outro dispositivo não exibirá seus registros. Use “Exportar backup” sempre que considerar necessário, para manter uma cópia segura ou transferir os dados.
